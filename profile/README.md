<h1 align="center">The Lupaxa Web Toolbox</h1>

**The Lupaxa Web Toolbox** contains tools, libraries and utilities for website development, maintenance and analysis.

The organisation sits between the Developers Toolbox and the Security Toolbox. It concentrates on the life of a website: building it, keeping it in good order, and understanding how it behaves.

## Focus

**The Lupaxa Web Toolbox** contains tools for areas including:

- Website development and page tooling
- Markup, styles, and front-end assets
- Static sites and publishing
- Content, link, and site maintenance
- Performance, availability, and accessibility analysis
- Structure, metadata, and crawl inspection

Whether you're building a site, maintaining one that is already live, or analysing how it is put together, **The Lupaxa Web Toolbox** aims to provide practical, reusable tools for website development, maintenance and analysis.
